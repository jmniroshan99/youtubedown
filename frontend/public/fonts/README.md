# Inter font

Source: `@fontsource-variable/inter` version **5.3.0** from the npm registry.

Only `inter-latin-wght-normal.woff2` is redistributed, under the versioned name `inter-latin-wght-v5.3.0.woff2`. It is the upright Latin variable-weight subset. No italic or additional script subsets are downloaded. The original SIL Open Font License is in `OFL-Inter.txt`.

The application preloads this one font and uses `font-display: swap`, with system fonts as fallback. User-entered text in other scripts is preserved and renders using the browser's fallback fonts. There are no Google Fonts or other remote font requests.
